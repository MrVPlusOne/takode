# Takode Todos

Use the Takode to-do tools for the user's persistent personal list. These records are separate from Codex goals and Quest records.

- Inspect with `todo_list` or `todo_show` before changing an existing item.
- Preserve authored Markdown when editing.
- Use the dedicated status and archive tools instead of encoding lifecycle changes into text.
- Report the changed item concisely after a mutation.
